# Raw Data

Store immutable source extracts, downloaded public files, and source notes here.

## Rules

- Preserve original filenames when practical.
- Do not manually clean or normalize files in this directory.
- Record the source URL and retrieval date in the normalized output or accompanying source note.
- Never commit passwords, API keys, private personal data, or restricted records.
- When a source is too large or legally unsuitable for Git, commit a source manifest rather than the file itself.
