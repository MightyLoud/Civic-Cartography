## Mixed constitutional structure

Texas Constitution Article VIII §14 provides the small-county sheriff/assessor-collector default but permits voters to create a separate assessor-collector. Presidio County uses the separate-office option. Article V §20 and Government Code §51.501 support one clerk performing both county- and district-clerk functions; Presidio uses that combined form.

The release therefore contains one Sheriff row, one Tax Assessor-Collector row, one combined District Clerk and County Clerk row, zero combined Sheriff/Tax rows, and zero duplicate component clerk rows.

## Commissioner geography

Official county ballots establish election precinct assignments:

- election precincts 1–2 → Commissioner Precinct 1;
- election precincts 3–4 → Commissioner Precinct 2;
- election precincts 5–6 → Commissioner Precinct 3; and
- election precinct 7 → Commissioner Precinct 4.

Current Texas Legislative Council polygons control exact geometry. All seven precincts are assigned, with zero overlap and zero union drift.
